# Почта команды: общая папка сообщений

Длинные сообщения друг другу не шлём в мессенджер, а кладём файлом сюда. Одна общая папка на двоих, без деления по адресатам: заходишь, `git pull`, смотришь новые файлы сверху по имени.

## Имя файла
`ГГГГ-ММ-ДД_ЧЧММ_автор_тема.md`, автор — `vitaly` или `dmitry`. Только латиница и дефисы, без пробелов и кириллицы: `2026-09-23_1420_dmitry_contract-ready.md`. Содержимое по-русски, UTF-8.

## Как писать
- Первая строка файла: кому и что нужно сделать, к какому часу.
- Дальше список пунктов; файлы репозитория называем путём (`contract/openapi.yaml`).
- Один файл — одно сообщение. Чужие файлы не правим: ответ — новым файлом.
- Просьба к чужой зоне — не «поправь строку N», а три пункта: **что вызвал → что получил → что ожидал**. Чинит владелец папки.
- Числа — цифрами, с единицей.
- Отправили — скажите голосом «посмотри в messages».
- **Ответ обязателен** — даже коротко: «принял, сделаю к 15:40».

## Отправка
`git add messages`, `git commit -m "час N (имя): сообщение <тема>"`, `git pull --rebase --autostash`, `git push` (по просьбе человека это делает Codex). Сообщение — тоже работа часа, коммит считается.

## Папка временная
По окончании работы `messages/` удаляется целиком: `git rm -r messages`, коммит «час N (Виталий): удалена почта», `git pull --rebase`, `git push`. Делает капитан до последнего коммита. Агенты (Codex/Claude) папку не пишут и не удаляют. Правило записано в корневом `AGENTS.md`.
