# Договорённость экрана и движка

Здесь — вопросы, которые экран задаёт движку, и пример ответа с настоящими полями: `openapi.yaml` + `examples/*.json`.

- Пишем **вдвоём вслух за первые 40 минут** (13:20–13:40), в GitHub к 13:40 — это коммит первого часа.
- Пишет Прораб (`server/`), коммитит и отправляет Codex. Виталий читает после `git pull`.
- Менять — только вдвоём вслух, в одном коммите: `openapi.yaml` + все затронутые `examples/`. **После 16:00 форма ответов заморожена** (только исправления значений).
- Экран строится на `examples/`; движок отвечает **ровно как образец**, `server/tests/test_contract.py` сверяет значения, а не только форму.
- Числа в образцах — цифрами и пересчитаны перед отправкой.
- Базовый шаблон (`/health` + `/api/chat`): `server/naryady/spravka/contract_template/` → копируется сюда в начале дня.
